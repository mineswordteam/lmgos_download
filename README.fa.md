# LMG OS (Logic Mind Grid)

**یک لینوکس جدید بر پایه‌ی دبیان** — دسکتاپ سبک، امن و نئونی آبی. ساخته‌ی **Minesword Team**. تاریخ انتشار: **۸ آبان ۱۴۰۵**.

[English](README.md) · [دفترچه‌ی فارسی](MANUAL.fa.md) · [User manual](MANUAL.en.md) · [یادداشت انتشار](RELEASE_NOTES.md)

> نرم‌افزار آزمایشی (بتا). قبل از نصب پشتیبان بگیرید.

## ویژگی‌ها
- Debian 13 «Trixie» + XFCE، تم مشکی و آبی نئونی، انیمیشن نرم پنجره‌ها
- **پنل کنترل LMG OS**: Update، RAM، Hardware، Test، Disk، Settings، Gaming
- **آپدیت امن**: اول دانلود، بعد نصب پیش از بالا آمدن دسکتاپ، و برگرداندن نسخه‌ی قبلی با یک کلیک
- **حالت گیمینگ**، حالت Light برای کامپیوترهای قدیمی، zram و earlyoom برای رم کم
- **اسکنر USB** (اختیاری، پیش‌فرض خاموش): بررسی و تعمیر فلش پیش از استفاده و مسدود کردن دستگاه‌های مشکوک
- برنامه‌های ویندوز با Wine / Bottles و برنامه‌های لینوکس با Flatpak
- فارسی و انگلیسی؛ نصب‌کننده‌ی گرافیکی (Calamares) با امکان رمزنگاری دیسک
- پشتیبانی گسترده از سخت‌افزار: AMD / Intel / NVIDIA، وای‌فای، بلوتوث، اندروید / آیفون

## دانلود
فایل ISO و `LMG-OS-amd64.iso.sha256` را از **Releases** بگیرید. با `sha256sum -c LMG-OS-amd64.iso.sha256` بررسی و با Rufus (حالت DD)، balenaEtcher یا `dd` روی فلش بنویسید. مراحل کامل: [MANUAL.fa.md](MANUAL.fa.md).

حداقل: پردازنده‌ی ۶۴ بیتی، ۲ گیگابایت رم، ۱۵ گیگابایت دیسک.
