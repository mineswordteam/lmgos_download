# LMG OS (Logic Mind Grid)

**A brand-new Linux based on Debian** — light, secure, neon-blue desktop. By **Minesword Team**. Release date: **October 30, 2026**.

[فارسی](README.fa.md) · [User manual](MANUAL.en.md) · [دفترچه‌ی فارسی](MANUAL.fa.md) · [Release notes](RELEASE_NOTES.md)

> Beta software. Back up your data before installing.

## Highlights
- Debian 13 "Trixie" + XFCE, black and neon-blue theme, smooth window animations
- **LMG OS Control Panel**: Update, RAM, Hardware, Test, Disk, Settings, Gaming
- **Offline-style updates**: downloaded first, installed before the desktop starts, one-click **restore previous version**
- **Gaming Mode**, Light mode for old PCs, zram + earlyoom for low RAM
- **USB scanner** (optional, off by default): checks and repairs drives before use, blocks suspicious devices
- Windows programs through Wine / Bottles, Linux programs via Flatpak
- English and Persian; graphical installer (Calamares) with disk encryption
- Wide hardware support: AMD / Intel / NVIDIA, Wi-Fi, Bluetooth, Android / iPhone

## Download
Get the ISO and `LMG-OS-amd64.iso.sha256` from **Releases**. Check it with `sha256sum -c LMG-OS-amd64.iso.sha256`, write it with Rufus (DD mode), balenaEtcher or `dd`. Full steps: [MANUAL.en.md](MANUAL.en.md).

Minimum: 64-bit CPU, 2 GB RAM, 15 GB disk.
